Release Notes
v2.0 α Navigation, Train & Profile
  • Added a global sidebar drawer accessible via the ☰ hamburger button — navigate between Exercise, Train, Profile, and future sections without leaving your current view
  • The GymLog wordmark appears beside the hamburger on all sidebar-accessible views, keeping the app identity consistent throughout
  • Added the Train section — start a Bulk, Cut, or Neither training phase with an optional target duration; the active phase card tracks the current day and shows a progress indicator against your goal
  • Log your body weight within an active phase; each entry shows an up/down delta against the previous weigh-in so you can track direction at a glance
  • Ending a phase archives it to a phase history list showing start and end dates, total duration, and the weight change over the phase
  • Added the Profile section — edit your name, set your height, select up to 12 training goals (Hypertrophy, Strength, Endurance, Fat Loss, and more), and view live stats: Total Workouts, Weekly Streak, and PRs Achieved
  • Tap your profile avatar to upload a photo (JPEG, PNG, WebP, GIF, or HEIC) — displayed in both the Profile page and the sidebar header; falls back to initials when no photo is set
  • Added Pause / Resume button during active sessions — freezes the timer without ending the session so rest periods don't inflate your logged duration
  • Added a Cancel Session confirmation modal to prevent accidentally discarding a session in progress
  • Added a finish guard — finishing a session with no exercises logged now asks you to confirm before saving an empty record
  • Added Export as Workout Plan in Reports — expand any session's exercise log and tap the button to open the plan editor pre-filled with those exercises, ready to save as a reusable plan
  • Added Increase Plates option in Progression Targets — when using plates mode the recommendation can suggest adding a full plate rather than a kg/lbs increment
v1.8 Interactive Feature Guides
  • Added a Help page in Settings with a swipeable carousel of animated feature guides — covering Session Types & Subtypes, Workout Plans, Copy Previous Set, and Progression Targets
  • Each guide shows a full GIF walkthrough alongside a plain-English description of the feature and how to use it
  • Dot indicators track your position in the carousel and reset to the first slide each time you open Help
v1.7.5 Unit Convertor & Bug Fixes
  • Added inline unit convertor in the Log Set modal — converts lbs → kg when kg is selected as your weight unit, and kg → lbs when lbs is selected; converts mi → km or km → mi for distance exercises based on your distance unit setting
  • Convertor is hidden in Plates mode and only shown for exercises with weight or distance tracking enabled
  • Added exercise search bar on the Exercises library page and inside the Add Exercise picker during active sessions — searches filter in combination with the existing Strength, Cardio, and User Added pills
  • Added a New Exercise button inside the Add Exercise picker during a running session — opens the New Exercise form and returns to the picker with the new exercise visible and selectable
  • Added edit support for user-added Session Types, Subtypes, and Exercises — tap the ✏️ button on any custom item to update its name, emoji, or other details
  • Added Export on Session Finish toggle in Settings → Data — when on, the Export dialog opens automatically each time you finish a session
  • Workout Plan dropdown on the Home screen now auto-selects the plan assigned to the chosen Session Type or Subtype; manually changing the dropdown overrides the auto-load, and selecting None prevents any plan from loading even if one is assigned
  • Fixed long notes being unreadable in the Notes viewer on the Reports screen — the note body now scrolls within a capped area while the session header and action buttons remain visible at all times
v1.7 Progression Targets & Session Set Logging
  • Added Progression Targets — automatically suggests the next weight to use when the Log Set modal is opened, based on your recent performance for that exercise
  • Two progression methods available: Double Progression (one qualifying session triggers a recommendation) and the 2-for-2 Rule (two consecutive qualifying sessions required for a more conservative increase)
  • Configurable targets: set your Min and Max rep range, the number of qualifying sets required per session, and the weight increment to suggest
  • Optional rep range mode — when enabled, a set only qualifies if reps fall within the Min–Max range rather than simply hitting the Max; Min Reps input is greyed out when this is off
  • Recommendation banner appears below the Weight/Plates field in the Log Set modal in green, with the suggested weight pre-filled and an ℹ️ button explaining why the recommendation was made
  • Added "Copy previous set values" toggle in Settings → Sessions — when on, the Log Set modal pre-fills reps, weight (or plates), and machine weight from the most recently logged set for that exercise
  • Copy previous set applies within the current active session only and correctly carries plates mode state across sets

Help

Feature guides

Session Types & Subtypes

Tap the Exercises tab and switch to Session Types to create your own training categories. Use the + button to add a new Session Type with a name, emoji, and colour. Expand an existing type to add Subtypes — for example a "Strength Training" type with subtypes like "Chest", "Back" or "Legs".

Workout Plans

In the Exercises tab switch to Plans to build a Workout Plan — give it a name, an emoji, and add exercises from your library. Assign the plan to a Session Type or Subtype via the link icon on the type card. With auto-load on, starting that session type automatically adds all the plan's exercises.

Copy Previous Set

Enable Copy Previous Set in Settings → Sessions to speed up logging. When you add a second set for an exercise the reps and weight from your last set are pre-filled — simply adjust any values and tap Log Set.

Progression Targets

Turn on Progression Targets in Settings → Progression Targets to receive automatic weight increase suggestions. Choose your method (Double Progression or 2-for-2 Rule), set your target reps and sets, and define the increase amount. When the criteria are met the Log Set form pre-fills the next suggested weight and shows a green banner.
