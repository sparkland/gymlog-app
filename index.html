Release Notes
v1.3.1 Bug Fixes & Test Automation
  • Fixed filter pill text misalignment in Exercises view caused by native browser button rendering
  • Fixed filter pill border clipping in Exercises view caused by overflow container collapsing top padding
  • Fixed horizontal scrollbar appearing on filter pills in the Add Exercise modal
  • Disabled Export and Clear History buttons on Reports when no sessions exist
  • Added Playwright E2E test suite with GitHub Actions CI on pull requests

  • Added Exercise Library with 30 default exercises
  • Added ability to create custom exercises
  • Added inline exercise and set logging during active sessions
  • Session history now shows exercise summaries in Reports
  • JSON and PDF exports include exercise data

  • Added Settings functionality
  • Added functionality to clear all stored data

  • Added Data Export functionality
